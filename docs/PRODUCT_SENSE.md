# Product Sense

The first useful version of this app is a safe, understandable NTE mod manager for Windows and macOS.

Success means a player can:

- point the app at an NTE install
- browse or import a mod
- install it safely
- toggle it on or off
- recover from mistakes without manual file surgery

The product should optimize for trust over density. The app is handling user files, so it must explain what it is doing and avoid silent destructive behavior.
