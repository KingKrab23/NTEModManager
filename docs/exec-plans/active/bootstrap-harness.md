# Bootstrap Harness

## Goal

Create the initial repository harness for an agent-friendly NTE mod manager project.

## Scope

- create a short `AGENTS.md`
- define the initial architecture map
- define product, frontend, reliability, and security rules
- define testing and hook expectations
- add a small validator for harness drift

## Acceptance criteria

- repository contains a readable top-level map
- core docs exist and are cross-linked
- a validation command can fail when the harness is incomplete

## Next likely plans

1. Electron application bootstrap
2. Lint, format, husky, and hook bootstrap
3. Typed IPC contract
4. Settings persistence
5. GameBanana API integration
6. Mod install pipeline
